# Stagger animation by information importance

**Use when:** Several pieces of content should appear in a deliberate reading order rather than all at once.

**Principle:** Reveal primary content first, followed by secondary and supporting content. Let adjacent stages overlap enough to feel connected while keeping the information hierarchy readable.

**Apply:**

- Classify animated content as primary, secondary, or supporting according to the target graphic's communication goal.
- Start primary content first.
- Start secondary content after the primary motion begins; start supporting content last when present.
- Prefer one batched Timeline choreography when multiple assignments form the sequence.
- Use relative dependencies and offsets when they express the intended order more clearly than unrelated absolute start times.

**Adjust:** Importance order, stagger interval, overlap, total duration, animation direction, and easing.

**Verify:** Primary content becomes readable before secondary details compete for attention, and the sequence still reads correctly when the total duration changes.
