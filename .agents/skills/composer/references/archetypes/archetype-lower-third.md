# Lower third

## Use when

The user asks for a name strap, speaker ID, guest identifier, location caption, quote attribution, or short contextual lower-third graphic.

## Default interpretation

Create one transparent, independently cued lower-third module in the lower broadcast-safe area. Use a two-line identity sample such as `MAYA CHEN` and `Senior Correspondent` unless the prompt implies a single-line caption.

## Semantic content

- Required: primary identifying text.
- Recommended: secondary role, affiliation, or context when the category implies it.
- Optional: logo/avatar, location or category kicker, social handle, and a user-requested accent color.

## Composition structure

- One lower-third sub-composition; separate persistent channel branding only when it already exists or is explicitly requested.
- Independent Text elements for primary and secondary lines and an Image slot for any intended asset.
- Public text controls for externally changed copy, plus image/color controls only for genuine operator inputs.
- No script by default; use direct links and Timeline/Update animation.

## Design rules

- Primary identity leads, secondary context supports, and decoration remains subordinate.
- Align text edges, baselines, panel padding, and any asset slot as one compact system.
- Keep the footprint away from critical lower-frame content and captions after inspecting the composition.
- Use a specific editorial, restrained, energetic, or premium visual thesis with one signature accent rather than generic decoration.

## Variations

One or two lines; left- or right-anchored; boxed, open, or accent-rail treatment; with or without image; identity, location, or quote attribution.

## Edge cases

Long names, long roles, one empty line, diacritics, mixed-case requirements, missing image, very short copy, and different aspect ratios.

## Ask only when

- The copy hierarchy cannot be inferred from the supplied text.
- Placement conflicts with known captions or an existing persistent graphic and no safe area is available.
- Mandatory official branding is missing.

## Verify

Confirm public copy controls and links; long and short samples remain readable without collisions; an empty optional line closes cleanly; missing assets do not leave an accidental hole; safe margins and contrast hold at output resolution; and settled In/Out plus any copy Update are visually complete.
