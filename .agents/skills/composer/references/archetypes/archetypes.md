# Graphic archetypes

Use this index only for sparse or category-level prompts. Select and read exactly one best matching card, then compile the task-specific brief through [../briefing.md](../briefing.md). If two candidates imply materially different output contexts, use the card whose trigger best matches the user's wording; ask only when the ambiguity changes the product and cannot be resolved from the active composition.

| Archetype | Select when |
| --- | --- |
| [Soccer score bug](archetype-soccer-score-bug.md) | Compact on-air soccer scoreboard, match-score overlay, or persistent score display. |
| [Soccer match card](archetype-soccer-match-card.md) | Larger preview, matchup, halftime, final-score, or full-frame soccer presentation. |
| [Lower third](archetype-lower-third.md) | Name/title identifier or short contextual caption in the lower part of frame. |
| [Starting lineup](archetype-starting-lineup.md) | Team roster or starters presentation, optionally including formation or portraits. |
| [Standings table](archetype-standings-table.md) | Ranked competition table with repeated rows and comparable statistics. |

Archetypes specify what makes a graphic complete and which defaults are safe. They do not prescribe a visual template, exact geometry, fonts, colors, timings, property paths, or widget IDs. Apply technique cards only after the brief establishes the content and lifecycle contract, and verify all implementation choices against the live Composer session.
